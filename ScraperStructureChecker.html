Scraper Structure Checker

Analisis struktur HTML + deteksi anti-bot (Cloudflare, captcha, dll.) untuk bikin adapter source.

Input

Disarankan: buka situs di tab biasa → Ctrl+U (View Source) → Select All → Copy → paste di sini → Analisis struktur. Itu cara paling akurat. Tombol Fetch URL sering gagal karena CORS / proxy (error 403 dari proxy ≠ situs sulit di-scrape). Proxy default: allorigins. Kalau gagal, kosongkan proxy atau paste HTML manual.

Catatan

Tool ini berjalan 100% di browser kamu. Tidak menyimpan data. Deteksi anti-bot bersifat heuristik (signature string/header), bukan bypass. Untuk situs dengan Cloudflare challenge interaktif, paste HTML setelah challenge lolos di browser biasa.
